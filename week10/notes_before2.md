# week09/tools.py 함수 정리

`tools.py`는 영화진흥위원회(KOBIS) 오픈 API로 **일별 박스오피스** 정보를 가져오는 도구 모음이다.

- API 키는 `secret.py`의 `API_KEY`에서 불러온다.
- 두 함수 모두 같은 주소(`BASE_URL`, `searchDailyBoxOfficeList.json`)에 `key`, `targetDt` 파라미터로 요청한다. (timeout 10초)

| 함수 | 하는 일 |
|------|---------|
| `get_boxoffice_rank_1(date)` | 그 날짜의 박스오피스 1위 영화 제목을 돌려준다 |
| `get_movie_audience(date, title)` | 그 날짜에 특정 영화의 관객 수를 돌려준다 |

## 1. `get_boxoffice_rank_1(date)`

그 날짜의 박스오피스 **1위 영화 제목**을 알려준다.

| 구분 | 내용 |
|------|------|
| 받는 것 | `date` (문자열) — 8자리 날짜. 예: `"20260824"` |
| 돌려주는 것 | (문자열) 1위 영화 제목. 예: `"오디세이"` |

동작 순서:
1. `key`, `targetDt`를 담아 API에 GET 요청을 보낸다.
2. 응답 JSON에서 `boxOfficeResult` → `dailyBoxOfficeList` 목록을 꺼낸다.
3. 목록의 첫 번째 영화(`movies[0]`)의 `movieNm`을 돌려준다.

## 2. `get_movie_audience(date, title)`

그 날짜 박스오피스에서 **특정 영화의 관객 수**를 알려준다.

| 구분 | 내용 |
|------|------|
| 받는 것 | `date` (문자열) — 8자리 날짜. 예: `"20260824"`<br>`title` (문자열) — 영화 제목. 예: `"오디세이"` |
| 돌려주는 것 | (문자열) 관객 수. 예: `"186,587명"`<br>순위에 없으면 안내 문장 |

동작 순서:
1. 1번 함수와 같은 방식으로 일별 박스오피스 목록을 가져온다.
2. 목록을 하나씩 돌며 `movieNm`이 `title`과 똑같은 영화를 찾는다.
3. 찾으면 `audiCnt`를 정수로 바꾼 뒤 천 단위 쉼표를 넣어 `"N명"`으로 돌려준다.
4. 끝까지 못 찾으면 `"'제목' 은(는) 날짜 순위에 없습니다."`를 돌려준다.

## 참고 사항

- 두 함수 모두 API 요청 실패나 응답 형식 오류에 대한 에러 처리가 없어서 예외가 그대로 발생한다.
- `get_boxoffice_rank_1`은 목록이 비어 있으면 `IndexError`가 난다.
- `get_movie_audience`는 제목이 띄어쓰기까지 정확히 같아야 찾을 수 있다.
- 두 함수가 API 요청 코드를 똑같이 반복하므로, 공통 함수로 묶을 여지가 있다.
